# 检测方案与应用台账

检测方案按应用台账里的资产生成检测清单，出作业指导书（Word），并能把清单里平台可自动执行的项一键建成组合任务。接口在 `/api/detect-schemes` 和 `/api/ledger`，规则代码在 `apps/api/src/modules/detect-schemes/generate.ts`。

## 清单生成与维护

- 生成只看需求配置里的资产和类别，按规则表（R1～R13）出项；同一资产同一检测入口只出一条。
- 重新生成时：
  - 规则生成、没被手工改过的项删掉重出；
  - 手工改过的项（改参数、标题、说明、启停都算）和手工添加的项保留，序号不变；
  - 新出的项排在已有项后面，跳过与保留项「资产 + 检测入口」相同的。
- **改过的项不再随台账刷新**：台账里资产的地址、关联的终端或评估对象变了，重新生成也不会更新这些项。要按台账的新情况出，删掉这一项再重新生成。
- 同一方案并发生成时按方案加锁，依次执行，不会出重复项。
- 需求配置里的资产从台账删除后，方案详情不再列出；用旧配置回填保存时会忽略这些已删的资产。

## 一键建任务

- 只取启用的、平台自动执行的项；参数不完整的列出缺的字段，不建。
- 一个组合任务最多 20 个子任务。可自动执行的项超过 20 个时返回 `SCHEME_TOO_MANY_ITEMS`，请勾选不超过 20 项分批建。
- 组合任务的默认名称是「方案名 · 日期」，日期按北京时间。

## 作业指导书

- 章节：检测概况、检测对象、检测项清单、作业步骤、配套工具、注意事项。
- 作业步骤按检测入口分组，每个入口一节，节内列出适用对象；工具的操作说明只在「配套工具」一章按工具写一次，作业步骤里写「见第五章」。
- 下载人没有查看工具中心的权限时，不写配套工具相关的内容。
- 实测 1000 个清单项、每个工具 400 行操作说明，生成约 1.5 秒，文件约 64 KB。

## 与租户转移的关系

终端、评估对象转移到别的租户时，其他租户台账里指向它们的关联会解除（台账资产本身保留），转移预检提示 `LEDGER_UNLINKED`。读台账时也按租户核对关联对象，不属于资产所在租户的当没关联。
