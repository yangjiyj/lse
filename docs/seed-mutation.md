# 种子库与变异扩展

## 概念

- **种子库**：已有的样本库，通常是内置库（如 Safety-Prompts 约 9.9 万题、TC260 186 题）或自有库。它只作为“原料”，不会被修改。
- **变异扩展**：从种子库按随机种子抽取若干题，对每道题套用所选的变换策略，生成一个**新的自有样本库**。
- 变换**只改变题面的表达形式**（包装、编码、混淆、多语种混排等），不新增任何有害内容或新的攻击话术；题目的分类、严重程度、是否应拒答、期望行为等元数据原样继承。
- 新库的 `source` 形如 `mutation:<种子库ID>:<随机种子>`，每道新题的元数据中记录 `parentQuestionId`（原题）、`strategy`（策略）、`seed`（随机种子），可追溯到原题。

## 使用方式

在样本库的种子库卡片上点击「变异扩展」，依次设置：

| 项 | 说明 |
| --- | --- |
| 新样本库名称 | 必填，不能与已有样本库重名 |
| 随机种子 | 可选；留空则自动生成并在结果里回显 |
| 抽样题数 | 1–1000；种子库题数不足时取全部 |
| 变换策略 | 按分组多选，最多 10 种 |
| 每题套用几种策略 | 默认 1；不能超过所选策略数 |

单次最多产出 5000 题（抽样题数 × 每题策略数）。变换后与原题相同、为空或过长的结果会被跳过，数量在结果里显示。

对应接口：

- `GET /api/question-sets/mutation/strategies`：策略列表与上限。
- `POST /api/question-sets/mutation`：创建新库，需要「新建样本库」权限，并写入审计日志（`question_set.mutation`）。

## 可用策略

规则类策略完全在本地确定性执行，不需要任何模型。

- **越狱话术包装**：指令覆盖、角色扮演越狱、开发者模式诱导、Skeleton Key 越狱、DAN 风格越狱、伪造指令层级、学术研究包装
- **编码转换**：Base64 编码、Hex 编码、ROT13 编码、URL 编码、摩斯编码
- **字符混淆**：Leetspeak 混淆、同形字符混淆、零宽字符混淆、双向文本控制符、Unicode Tag 走私、全角字符混淆、Emoji 分隔走私、ASCII Art 包装、GCG 风格后缀压力测试
- **间接载体包装**：Markdown 权威伪装、JSON 系统消息伪装、XML 结构化注入、YAML 结构化注入、CSV/表格上下文注入、外部工具输出间接注入、RAG 文档污染、载荷分片重组
- **多语种混合**：多语言混排、句中代码切换
- **多轮 / 迭代式包装**：Crescendo 多轮诱导、Many-shot 示例漂移、PAIR 迭代优化模拟、TAP 树搜索模拟
- **大模型改写**（需要配置改写模型，默认不选）：大模型改写、大模型等价变体。改写模型沿用生成器增强的 `ENHANCE_LLM_*` 配置；未配置时界面置灰，接口返回 400。

## 可复现性

对规则类策略，**相同的种子库、抽样题数、随机种子、策略组合，一定得到同一批题**：

- 抽样位置只由（随机种子，种子库题数）决定，按题目 ID 排序后取位；
- 每题选哪几种策略、变换中的随机成分，只由（随机种子，原题 ID，策略）决定，与其他题无关。

注意：

- 种子库的题目数量或内容发生变化后，同一随机种子会抽到不同的题；
- 大模型改写类策略的输出本身不确定，不保证复现；
- 抽样不会一次性把整库载入内存：先分页只读题目 ID 命中抽样位置，再按小批量读取正文，因此对 9.9 万题的大库同样适用。

## 推荐用法

- **对 Safety-Prompts 抽 500 题 × 3 种策略**：抽样题数填 500，选「指令覆盖」「Base64 编码」「全角字符混淆」三种，每题套用 3 种，约产出 1500 题，覆盖话术包装、编码、字符混淆三类表达形式。
- **想要更大的覆盖面但保持每题只有一个变体**：多选几种策略，每题套用 1 种，由种子随机分配。
- 把「随机种子」和新库名一并记录在评估方案里，需要复现或复核时直接用同一组参数重新生成。
- 先用小规模（如 50 题）试跑，在新库里抽查题面，确认策略符合预期后再放大。
