# 批量评估与横向对比

一次创建多个标准 API 模型对象的评估计划，对同一套冻结样本执行评估，输出对象报告和总体报告。当前支持轮询、顺序、并行执行、暂停继续、异常重试、请求预算、接口 RPM 限额与分页证据。

## 适用范围

- 对象类型为已启用的 `MODEL`。真实智能体、自适应红队和网关防护前后对照保留为独立评估流程。
- 每对象 1 至 100,000 个样本；每计划最多 50 个对象，合计最多 1,000,000 个对象与样本组合。
- 样本去重后不足会拒绝创建，不重复扩充凑数；同题的判定规则冲突也会拒绝。
- 模型判定使用创建时选定的独立 `JUDGE` 对象，不能与任一被测对象使用相同的接口和模型组合。规则初筛为客户明确选择的另一种方式。

## 执行与恢复

计划、题目及公开模型参数保存快照。配置指纹包含调用配置，密钥不会回传客户端或写入报告。对象或评审配置、访问范围发生变化时暂停原计划，以新计划执行新的口径。

独立队列为 `batch-evaluations`。Worker 持有计划租约，使用心跳续租；恢复调度每 60 秒检查已经启动且失联的计划，不自动启动草稿。数据库父计划行锁和唯一约束保护请求预留、尝试编号、响应及结果写入。

暂停停止派发新调用，允许已发出的请求保存响应；在途调用结束并释放租约后可继续。已保存的目标响应和本次尝试窗口的有效评审响应会复用；显式重试异常只重试异常或待判定样本，并开启有限的新尝试窗口。

接口 RPM 按接口源站与凭据组合在 Redis 中共享，目标调用和评审调用都纳入控制。全局并发与每对象并发分别限制。当前不提供 TPM 或货币金额预算。

请求预算同时计入目标与评审调用。预算采用请求前原子预留，可能包含崩溃前已预留但尚未确认发出的尝试。上游已处理而本地未保存时，不能普遍保证远端零重复调用；平台保留不确定尝试并限制补发，不承诺恰好一次外部调用。

时间上限从首次启动起按墙钟计算，包含暂停时间。达到时间或请求上限暂停并保留结果；用户可增加上限后继续。取消为终态，需要新计划重新执行。

## 结果与报告

主判定为 `UNKNOWN` 时，敏感信息扫描未命中不能将其覆盖为通过；明确敏感信息风险可以产生风险命中。模型评审只接受严格 JSON 的 `PASS/FAIL/UNKNOWN` 枚举，无法解析或不可用时保留异常或待判定，不能暗中降级为规则通过。

有效判定仅包含通过和风险命中。异常、空响应、待判定和未执行样本分别保留，不能作为通过。总体风险与证据不足可以同时存在，高危和严重风险不被总体平均分抵消。当前报告不输出确定的安全排名或合规认证结论，自动风险命中需人工复核。

每对象明细报告与总体报告均提供 UTF-8 Markdown 下载，文件名使用客户可读标题。证据接口分页查询，避免浏览器一次加载十万条回答。

## 权限

计划默认按创建人隔离，内置管理员可跨创建人访问；普通的编辑用户权限不能扩大计划访问范围。

| 操作 | 权限 |
| --- | --- |
| 创建 | `eval_task:create`、`model_target:read`、`question_set:read` |
| 列表和详情 | `eval_task:read` |
| 启动 | `eval_task:create` |
| 暂停、继续、取消、异常重试 | `eval_task:re_eval` |
| 样本证据 | `eval_task:read`、`eval_task:log_view` |
| 查看报告 | `eval_task:read`、`report:read` |
| 下载报告 | `eval_task:read`、`report:download` |

创建和执行操作继续受现有 `web_ai` 授权检查约束。目标调用复用现有出口校验与关联签名，不接受计划中任意注入的调用地址。

## 发布接入

迁移：`apps/api/prisma/migrations/20260930090000_batch_evaluations/migration.sql`。仅新增批量评估相关表和约束，不修改探针相关表。

部署时在目标环境执行 `pnpm exec prisma migrate deploy` 与 `pnpm exec prisma generate`，同时更新 API、Web 和 Worker，保证专用队列及恢复调度可运行。现有对象、普通评估任务和报告流程保持原入口。

生产发布应基于已验证提交，迁移后同时更新 API、Worker 和 Web；模拟验收与目标客户接口验收分别记录，不能互相替代。

## 验证

新增测试位于 `apps/api/test/batch-evaluations*.test.ts` 和 `apps/web/src/pages/BatchEvaluationsPage.test.tsx`。覆盖样本冻结、配置变化、归属权限、请求预算、过期租约、评审故障、评审响应恢复、重试窗口隔离、全局并发、真实 HTTP 关联及对象报告范围。

容量模拟脚本：`scripts/verify-batch-evaluations.mts`，必须指向独立测试库并设置 `LSE_TEST=1`。默认执行 10 个对象各 10,000 个样本，走真实数据库、执行器、尝试记录和报告汇总，但目标响应使用模拟调用，不消耗付费模型配额。通过该验收不能宣称实际模型安全或承诺真实接口执行时长。

隔离联调脚本：`scripts/batch-evaluations-preview.mts`，同样强制检查测试数据库边界，模拟接口 19491、API 18193；开发 Web 15174 通过代理接入。预览数据库、Redis 和模型均与现有运行环境分开。
