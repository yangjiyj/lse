# LSE 1.0.2 红队策略兼容修复

## 发布范围

- 基线：`lse-v1.0.1@22aaace4ee5825ee6b4c76e74103c14dd19af3e1`
- 版本：`1.0.2`
- 架构：`linux/amd64`
- 最终提交、镜像 ID、离线包位置及 SHA-256 以本次发布验收记录为准。

## 根因与修复

旧设置页允许把中文展示词写入 `redteam.config.moves`，红队执行器却只接受内部策略 ID。任务进入执行后索引不到策略定义，触发 `Cannot read properties of undefined (reading 'name')`。

1.0.2 在红队配置解析边界统一规范化策略值：

- 正式策略 ID 原样保留并去重。
- 历史中文值和当前策略中文名称映射为正式 ID。
- 未实现的自定义值不再进入执行器。
- 全部值均无效或列表为空时回退平台标准策略组合。

该兼容层不修改模型对象、接口、密钥、独立性校验、历史任务、报告或原始系统设置记录。
