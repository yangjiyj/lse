# LSE 1.0.8

本版本基于联调冻结源码 2d618ec465722047039ce8d8e7dd7b11ce5645ed 发布，整套联调 release ID 不作为产品版本号。

- 智能体实例与工具配置绑定、严格工具参数验证、受限原生 shell 模拟、UNKNOWN 传播与失败项复测闭环。
- 拒绝重复 JSON 参数键与原始/解析参数不一致输入，避免危险原生参数被覆盖后误判通过。
- 补齐外部资产评估审计的中文标签。
- 支持受限平台连接器、批量结果回调和外部资产评估；凭据与地址由部署配置和平台管理设置提供。
- 保留原有模型评估、样本库、报告、账户、权限、任务和网关联动能力。
- 离线部署补齐模型文件扫描只读目录及上传持久卷。
- 增加 /api/version 与镜像版本/提交标签，统一产品版本 1.0.8。

## 升级与回滚

本次验证起点为 1.0.7-e184916d69f7。新增五项迁移，均为增加权限定义、字段、表和 AGENT 枚举，不删除原数据；枚举扩展不能用简单降迁移删除。应用回滚保留向前兼容的数据库。需要完整数据库回退时停写并使用升级前备份恢复，明确处理备份后新增数据。

验证平台为 Ubuntu 24.04 x86_64 + systemd。离线包包含 Docker/Compose、应用/Web/PostgreSQL/Valkey 和安全核验镜像、规则与固定漏洞库。模型推理仍须连接客户已有且授权的模型服务，包内不含模型权重。

源码内测试和联调启动工具不进入应用镜像。包内配置不含真实账户凭据、生产数据或证书私钥。本版本不要求升级或重启 JJDGuard。
