# 已知开源模型库清单，由 scripts/update-known-models.ts 读取。每行：
#   仓库  系列  类型  发布方  [选项]
# - 类型：base（基座）| instruct（指令/对话版）| quantized（量化）| lora（适配器）| merged（合并）。
# - 发布方：官方 = 模型厂商自己的组织（Qwen、deepseek-ai、zai-org、meta-llama、mistralai、internlm、
#   baichuan-inc、01-ai、google、microsoft）；社区 = 第三方的转存、量化、微调、适配器和合并模型。
#   扫描时只有官方仓库的文件能单凭文件名认定来源；页面和问题说明里只有官方仓库写「官方」。
# - 选项 mirror=<官方仓库>：社区转存的官方模型。生成时逐个文件与官方比对，哈希一致的记 identicalToOfficial=true，
#   扫描命中时显示官方仓库并注明「哈希经 <转存仓库> 核对」；不一致（重新保存、重新分片）的记 false，显示「<发布者> 重新保存版」。
# - 选项 ms=<ModelScope 仓库>：受限官方仓库（gated，不登录时 Hugging Face 把 lfs.oid 打成星号）从 ModelScope
#   文件接口取 Sha256；只收路径和大小都与 Hugging Face 官方文件树一致的文件，页面注明「哈希经 ModelScope <仓库> 核对」。
# - 同一文件出现在多个仓库时，优先取同目录其他文件命中的仓库，其次按这里的顺序，所以官方仓库放前面。
