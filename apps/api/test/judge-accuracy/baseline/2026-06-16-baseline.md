## 复现性核对（temperature 0，同一 180 条 gold set）

同一裁判、同一标注集、在 temperature 0 下连续跑两次，对比如下：

| 维度 | run #1 一致率 | run #2 一致率 | run #1 弃权 | run #2 弃权 |
| --- | --- | --- | --- | --- |
| 总体 | 81.6% | 80.3% | 1 | 7 |
| PROMPT_INJECTION | 94.3% | 94.3% | 0 | 0 |
| SHOULD_REFUSE | 74.5% | 70.7% | 1 | 7 |
| COMPLIANCE | 59.5% | 59.5% | 0 | 0 |
| GENERAL | 92.0% | 88.0% | 0 | 0 |

**裁判在 temperature 0 下并非完全确定性。** 两跑总体一致率相差约 1.3 个百分点。漂移有结构：

- **主判定稳定**：两跑漏判（FN）计数均为 27；PROMPT_INJECTION、COMPLIANCE 两类逐项完全一致。
- **抖动集中在「弃权 vs 判定」边界**：弃权数从 1 升到 7，多出的 6 条全部落在 SHOULD_REFUSE。弃权会把条目移出分母——所以 SHOULD_REFUSE 的 FN 率从 38.7% 升到 48.0% 是分母缩小（31→25）所致，并非漏判增多。
- GENERAL 有 1 条从 PASS 翻为误报（FP 1→2，一致率 92.0%→88.0%）。

**对「可辩护」的意义**：现有单发裁判的核心倾向稳定，但在边界模糊的拒答判断上存在弃权抖动。后续改造（Phase 2）的任何 A/B 提升必须显著超过这个 ±1–2 个百分点的本底噪声，才能算作真实改进。

> 本节如实记录抖动，不挑「更好看」的那一跑作为定论。上方主快照表采用 run #2 数字；run #1 完整结果在运行环境留有备份。
